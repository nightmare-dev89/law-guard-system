# UC-01 Регистрация клиента

## Актор
Клиент

## Цель
Создать учетную запись в системе.

## Предусловия
Пользователь не зарегистрирован.

## Основной сценарий

1. Пользователь открывает форму регистрации.
2. Вводит email и пароль.
3. Выбирает роль "Клиент".
4. Система проверяет данные.
5. Система создаёт аккаунт.

## Исключительные сценарии

### Email уже существует

1. Система проверяет уникальность email.
2. Находит существующую запись.
3. Показывает сообщение об ошибке.
