# UC-01 Регистрация клиента

## 1. Общая информация

**Название:**  
Регистрация клиента

**Актор:**  
Клиент

**Цель:**  
Создать учетную запись клиента в системе Law Guard.

---

## 2. Предусловия

- Пользователь не имеет учетной записи в системе.
- Пользователь находится на странице регистрации.

---

## 3. Основной сценарий

1. Клиент открывает форму регистрации.
2. Клиент вводит email и пароль.
3. Клиент выбирает роль "Клиент".
4. Система проверяет корректность введённых данных.
5. Система создает учетную запись пользователя.
6. Система создает профиль клиента.
7. Система предоставляет доступ в личный кабинет.

---

## 4. Исключительные сценарии

### 4.1 Email уже существует

1. Клиент вводит email.
2. Система проверяет наличие email в базе.
3. Система обнаруживает существующую учетную запись.
4. Система выводит сообщение:
   "Пользователь с таким email уже зарегистрирован".

### 4.2 Некорректные данные

1. Клиент вводит данные в неверном формате.
2. Система отображает ошибку валидации.
3. Клиент исправляет данные.

---

## 5. Результат

После успешного завершения сценария:

- создан пользователь;
- создан профиль клиента;
- пользователь может войти в систему.
